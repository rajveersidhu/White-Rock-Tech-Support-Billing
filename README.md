# White Rock Tech Support Billing

Free browser-based billing for White Rock Tech Support.

## Features

- Estimates and invoices
- Estimate to invoice conversion
- Customer history
- Labour and parts line items
- Discounts
- Optional tax toggle
- Paid / unpaid tracking
- Print or Save as PDF
- Email invoice/estimate drafts
- E-transfer instructions
- Configurable Square payment link
- Local browser storage
- JSON backup export/import

## Privacy and security

Customer and billing data is stored in your browser on the device where you use the app. GitHub Pages does not receive that data.

Do not use this on a shared/public browser profile. Export backups regularly.

The app intentionally does not collect or store card numbers. Use a Square-hosted payment link for card payments. Never put Square secret keys, passwords, or access tokens into this app or a public repository.
